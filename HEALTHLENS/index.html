About This Project

MediGuide is a college project: an information portal where people can read about common diseases, check which conditions match their symptoms, calculate BMI, and find hospitals near them.

Features

  • Disease library with search and category filter
  • Symptom checker and BMI calculator
  • Live nearby hospital finder (browser location, OpenStreetMap data, Leaflet map)
  • Save favourite conditions (stored in your browser)
  • Dark mode and responsive design

Technologies

HTML5, CSS3, JavaScript (ES6), Geolocation API, Leaflet.js, Overpass API, localStorage.
